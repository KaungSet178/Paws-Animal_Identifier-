# Planned Trait Sources

This file records candidate datasets for Phase 2. No trait values are populated merely because a source is listed here.

## ASM Mammal Diversity Database (MDD)

Purpose: taxonomy, current accepted names, higher classification, common names and country-level occurrence context.

Project policy: MDD remains a **secondary taxonomy enrichment source**. It must not overwrite the canonical 2024 Myanmar checklist scientific names.

- https://www.mammaldiversity.org/
- Current project enrichment target: MDD v2.5

## PanTHERIA

Purpose: global mammal quantitative/ecological variables, including adult body mass, adult head-body length, adult forearm length, activity cycle and other ecological/life-history fields.

- DOI: https://doi.org/10.1890/08-1494.1
- Dataset landing information: https://doi.org/10.6084/m9.figshare.c.3301274.v1
- License reported by Open Traits Network: CC BY

Safety note: specimen measurements such as bat forearm length are internal data only and must not become questions that require wildlife handling.

## EltonTraits 1.0

Purpose: species-level foraging attributes of birds and mammals; mammal fields include body mass, nocturnality, diet and foraging stratum.

- DOI: https://doi.org/10.1890/13-1917.1
- Dataset: https://doi.org/10.6084/m9.figshare.c.3306933.v1
- License: CC BY 4.0

## PHYLACINE

Purpose: broad mammal macroecological traits, including body mass and terrestrial/aerial/freshwater/marine/life-habit variables.

- DOI: https://doi.org/10.1002/ecy.2443
- Dataset: https://doi.org/10.5061/dryad.bp26v20
- License reported by Open Traits Network: CC0

## Amniote life-history database

Purpose: body mass and other life-history measurements for birds, mammals and reptiles; useful primarily as a cross-check or gap-filling quantitative source.

- DOI: https://doi.org/10.1890/15-0846R.1

## Visual morphology sources

No single global dataset provides all observable traits required by this project (coat pattern, ear shape, snout shape, bat noseleaf, cetacean dorsal-fin form, etc.). These will be curated separately from identifiable authoritative sources. Source citation is mandatory for every populated value.
