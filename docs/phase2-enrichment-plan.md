# Phase 2 Enrichment Plan — Simple Observable Traits

## Priority

User-answerable visible traits now take priority over quantitative measurements.

No biological trait value will be populated without an identifiable source and a matching provenance row.

## Pass A — distinctive, easy traits

Start with the most distinctive orders and species where ordinary observation can provide high-confidence traits:

- Proboscidea
- Pholidota
- Sirenia
- Dermoptera
- Lagomorpha
- larger Artiodactyla/Perissodactyla
- Primates
- distinctive Carnivora

Populate obvious characteristics such as body form, body covering, horns/antlers, tusks, quills, gliding membrane, tail appearance and major markings.

## Pass B — moderate difficulty

Continue with:

- common/distinctive Rodentia
- Eulipotyphla
- Cetacea
- less distinctive Carnivora and ungulates

## Pass C — cryptic groups

Chiroptera and visually similar small rodents require extra caution. Only add traits that can actually be observed safely or in an ordinary photograph. If species-level visual separation is not defensible, mark the later identification level as genus/family rather than inventing fine traits.

## Source types

Preferred sources for visual morphology:

- peer-reviewed species descriptions or revisions
- authoritative museum/species accounts
- established mammal field guides and identification references
- reliable conservation/species profiles when they explicitly describe visible morphology

## Provenance

Every nonblank value in mammal_traits.csv requires an exact matching row in trait_provenance.csv with source name, source type, URL/citation where available, access date, confidence and notes.
