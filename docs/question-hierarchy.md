# Adaptive Question Hierarchy

The user never selects a mammal order or category.

## Opening questions

The reasoning engine may choose among only five easy observations:

1. What was most noticeable on its body? — fur/hair, scales, quills, smooth-looking skin.
2. Which overall body shape looked closest?
3. How did you see it moving?
4. Where did you see it?
5. Roughly how big did it look? — comparison with familiar animals, not a measurement.

The engine chooses the most discriminating available question rather than asking all five in a fixed order.

## General follow-up

When useful, it may ask about:

- tail impression
- main color
- large body pattern
- ear prominence
- simple snout shape
- visible foot type
- time of sighting

## Specialized questions

Specialized questions are gated. A user should not see a bat nose question unless bat candidates are meaningfully represented, or a horn-shape question unless horned ungulates remain plausible.

Specialized pools exist for Chiroptera, Rodentia, Primates, Carnivora, Lagomorpha, Eulipotyphla, Pholidota, Proboscidea, Dermoptera, Scandentia, terrestrial ungulates, Cetacea and Sirenia.

## Stopping behavior

The system must not force species-level identification. If ordinary visible traits cannot reliably separate close species, return genus, family, or insufficient evidence.
