# Simple Observable Trait Architecture

## Goal

The identification system must ask questions that a normal user can answer from a quick sighting or an ordinary photograph. It must not require wildlife handling, measuring, weighing, specimen examination, dental examination, skull measurements, or specialist equipment.

## Design rule

A user-facing trait is included only if it is reasonably noticeable without touching the animal.

Examples of acceptable observations:

- general body shape
- body covering
- rough size compared with familiar animals
- movement actually seen
- where it was seen
- main color and large markings
- obvious tail, ear, snout, horn, antler, tusk or quill features
- highly visible bat nose shape in a suitable photo
- highly visible whale/dolphin dorsal fin or beak

Examples deliberately excluded from user questions:

- exact body length or height
- body mass
- bat forearm length
- skull or tooth measurements
- dental formulas
- microscopic hair features
- genital or specimen characters
- measurements requiring capture or restraint

## Current scope

The simplified schema contains 29 user-observable traits. There are no direct measurement traits in the question system.

The system begins with five broad questions and activates specialized traits only when candidate relevance is high enough.

## Unknown answers

Every question must offer a Not sure option. Unknown evidence is neutral and must never be treated as a mismatch.

## Accuracy

The trait matrix starts blank. A nonblank species trait may only be added together with a provenance record identifying the source. Traits must not be generated from taxonomy or intuition.
