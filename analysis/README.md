# Phase 3A analysis outputs

Generated from the current 75-species source-backed trait subset.

- `species_readiness.csv` — conservative missing-data compatibility simulation
- `trait_discrimination_metrics.csv` — coverage and elimination value per trait
- `high_similarity_pairs.csv` — pairs with >=80% agreement across at least 3 jointly known traits
- `exact_profile_collisions.csv` — exact whole-profile collisions

Missing candidate data never eliminates a candidate. This intentionally understates readiness rather than overclaiming confidence.
